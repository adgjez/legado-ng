# 角色一致性（AI 漫画）

漫画垮掉，十有八九是**角色跳变**：同一人换张脸、换身衣服、换种画风。这一节是防跳变的唯一手段。

## 1. 先建角色锚点

每生成一个字之前，先把出场角色整理成**设定卡**。给用户看一眼再批量生成；用户没回就用你的设定往下走，但开场要说明你定了什么。

```
角色：小林
性别/年龄：男 / 28 / 职场新人
外貌关键词：圆脸、单眼皮、黑框圆眼镜、黑色短发略凌乱（右鬓一撮翘起）、偏瘦、175cm
服装：白衬衫 + 深蓝牛仔裤 + 白运动鞋 + 左手小米手环
性格：较真、易焦虑、表面淡定
标志性动作：思考时右手扶眼镜
```

## 2. 锁定 3–5 个不可变特征

每个角色挑 **3–5 个跨格必须出现**的特征作为锚点，写进每一格的 prompt：

- 右鬓一撮翘起的头发（所有画面必须出现）
- 黑框圆眼镜
- 左手小米手环
- 衬衫最上面一颗扣子永远不扣

> 锚点要"可画、可辨认、不易被姿势遮挡"。发型、眼镜、配饰比"温柔的眼神"靠谱得多。

## 3. 表情库 + 色板锁定

- **表情库**：给常用表情各写一句固定描述（neutral / panic / happy / determined / exhausted），分镜时直接选，不要每次重编。
- **色板锁定**：角色关联固定色板（肤色 / 发色 / 服装色），跨场景不变。环境光可以变，但角色本体颜色别变。

## 4. 垫图链：一致性靠"看得见前面"

回顾 SKILL.md 的三条硬规则——**除第 1 格外，每一格的 `references` 都带上一格的 `local_path`**。

- 第 1 格没有垫图，要一次把**画风定死**：风格、光线、色调、镜头语言全写进 prompt，后面才稳。
- 第 2 格起，除了本格画面描述，务必带上一格的本地路径作为参考图。模型会据此保持人物与画风。
- 换画风需求时，从新的一组第 1 格重新定调，并用新的 `project_id` 隔离，不要和旧组混在一起。

## 5. 一致性自检清单

生成完遍历一遍，逐项核对：

- [ ] 同一角色的脸型 / 发型 / 眼镜 / 配饰在每格都出现
- [ ] 服装颜色跨格一致，没有凭空换衣
- [ ] 画风、线条、网点密度没有突变
- [ ] 背景光线衔接自然，没有硬切到另一个世界观
- [ ] 角色相对位置 / 朝向没有无理由漂移

发现问题就**单独重生成那一格**——复用它的 `shot_index`，垫图仍用它的前一格，不要整组重来。
