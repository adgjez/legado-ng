# 分镜拆解（AI 漫画）

把用户给的文本切成一组**顺序连续、叙事完整**的漫画分镜。拆镜没想清楚就先别生成——后一格要能接上前一格。

## 1. 先解析原文

拿到文本后，先抽这些信息，必要时回给用户确认：

| 维度 | 抽什么 | 用在哪 |
|---|---|---|
| 主题 / 情感基调 | 讲什么、暖/悲/燃/搞笑/悬疑 | 定画风与节奏 |
| 场景序列 | 按时间线列出地点+时间+环境 | 分镜的场景字段 |
| 出场人物 | 姓名、外貌、服装、性格 | 角色锚点（见 `character.md`） |
| 关键台词 / 旁白 | 适合做气泡或旁白的片段 | 每格的 dialogue / caption |

文本超过 2000 字时，先摘要再拆镜，不要硬吞。

## 2. 分镜粒度

层级：**话 → 页 → 格**。一次对话通常只做一话、几页、若干格。

| 文本长度 | 建议格数 |
|---|---|
| 1–3 句 | 4–6 格 |
| 一段 / 一首歌词 | 6–9 格 |
| 完整故事 | 9–12 格（可分批） |

单次默认不超过 12 格；想更多就分批，每批各自用同一 `project_id`。

## 3. 每一格的字段

拆出来的每一格都要能直接交给生图，不能只是文学描述：

- **景别**：远景 / 全景 / 中景 / 近景 / 特写
- **角度**：平视 / 俯视 / 仰视 / 主观视角
- **构图**：三分法 / 对称 / 对角线 / 框架式
- **角色**：谁出镜、位置、动作、表情
- **背景**：场景描述（转成视觉 prompt）
- **台词 / 旁白**：气泡内容、类型、位置
- **情绪**：本格要传达的情绪关键词

**景别怎么用**：远景建场与转场；中景是对话主力（膝盖以上）；近景讲情绪（胸以上）；特写压关键细节（脸 / 手 / 物）。

## 4. 节奏：起承转合

- 头 1–2 格：建立场景与氛围，把画风、光线、色调、镜头一次定死。
- 中间格：推进剧情，展示冲突或情绪。
- 尾 1–2 格：收束或点睛，**不烂尾**。
- **一格只装一个动作或一个情绪**。别把两句台词 + 三个动作塞进一格。

## 5. 分镜表（给用户确认的格式）

```
【漫画分镜方案】共 N 格

第1格 — 标题
场景：xxx
角色：xxx（动作/表情）
镜头：远景 / 平视 / 三分法
台词/旁白：「xxx」
情绪：xxx

第2格 — 标题
...
```

## 6. 内部结构化（模型自用，不必传给工具）

生成前把分镜落成一棵结构，方便逐格映射参数：

```json
{
  "project_id": "comic_书名_20240315",
  "panels": [
    {
      "shot_index": 1,
      "shot": "远景",
      "angle": "平视",
      "scene": "清晨空荡的校园走廊，晨光从窗洒入",
      "characters": [],
      "dialogue": null,
      "emotion": "平静",
      "prompt_hint": "wide shot, empty school hallway at dawn, sunlight through windows, peaceful, symmetrical composition"
    },
    {
      "shot_index": 2,
      "shot": "近景",
      "angle": "平视",
      "scene": "少女站在走廊，短黑发、校服",
      "characters": ["小林"],
      "dialogue": { "speaker": "小林", "text": "只剩三小时了……", "bubble": "thought" },
      "emotion": "焦虑",
      "prompt_hint": "close-up, girl with short black hair in school uniform, worried eyes, soft morning light, centered"
    }
  ]
}
```

`shot_index` 从 1 递增、不重复、不从 0 开始；它就是分镜顺序的唯一依据。

## 7. 质量准则

- 相邻格之间背景 / 光线 / 角色要能接上，不能突然换场地又不交代。
- 一格一动作、一格一情绪，信息不过载。
- 台词短、适合气泡，四格漫画最后一句要有落点。
- 角色外貌足够具体，能支撑后续绘制（见 `character.md`）。
