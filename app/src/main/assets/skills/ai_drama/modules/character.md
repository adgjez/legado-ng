# 角色圣经与资产清单（AI 漫剧）

漫剧对一致性的要求比漫画更狠——漫画只是静态衔接，漫剧要在**时间维度**上保持人物、服装、场景、道具不漂移。本文件是防漂移的唯一手段。

## 1. 数字资产清单（先建 ID 体系）

为角色 / 场景 / 道具 / 母题 / 服装状态分配稳定资产 ID，后续所有 prompt 只引用 ID，不重新描述：

| 前缀 | 含义 | 示例 |
|---|---|---|
| `CHAR_` | 角色 | `CHAR_xiaolin_01` |
| `SCN_` | 场景 | `SCN_office_01` |
| `PROP_` | 道具 | `PROP_phone_01` |
| `MOTIF_` | 视听母题（如速度线 / 特定光） | `MOTIF_speedline_01` |
| `COSTUME_` | 服装状态 | `COSTUME_xiaolin_work_01` |

每个资产标注：版本状态、来源场次、连续性锁定、资产变更记录。换装 / 换场景时升版本号，不悄悄改描述。

## 2. 角色圣经（固定前缀）

每个角色写一份设定卡，作为**所有人物类 prompt 的固定前缀**。只有动作 / 场景可变，外貌不动。

```
CHAR_xiaolin_01 角色圣经（固定前缀，勿改）
性别/年龄：男 / 28 / 职场新人
脸：圆脸、单眼皮、黑框圆眼镜
发：黑色短发略凌乱，右鬓一撮翘起
体型：偏瘦、175cm
服装：白衬衫（最上扣不扣）+ 深蓝牛仔裤 + 白运动鞋
配饰：左手小米手环
性格：较真、易焦虑、表面淡定
标志动作：思考时右手扶眼镜
色板：肤色 #e8c9a8 / 发 #1a1a1a / 衬衫 #f5f5f5 / 牛仔 #2b3a55
```

每个角色挑 **3–5 个不可变特征**作锚点：右鬓翘发、黑框眼镜、左手手环、衬衫最上扣不扣。这些词必须进每一镜的人物 prompt。

## 3. 一致性约束（红线）

- 复用角色 / 场景 / 道具**必须引用资产 ID 与角色圣经固定描述**，禁止换脸、换装、空间漂移、母题误用。
- 画风、线条、色调跨镜锁定；环境光可变，但角色本体颜色不变。
- 第 1 镜关键帧定调后，后续关键帧用 `references` 垫图继承。
- 所有输出区分「原文明确 / 合理推断 / 创作建议」，不把 AI 建议写成剧本事实。

## 4. 一致性自检清单

生成完遍历：

- [ ] 同一角色的脸 / 发型 / 眼镜 / 配饰每镜都出现，没有换脸
- [ ] 服装颜色与资产清单一致，没有凭空换衣
- [ ] 场景母题（光线 / 速度线）跨镜连续，没有硬切世界观
- [ ] 角色位置 / 朝向跨镜不无理由漂移
- [ ] 道具（如手机）同一件贯穿，没有偷偷替换

发现单项问题就**单独重生成那一镜**：复用 `shot_index`，关键帧与首尾帧重做即可。
