# 分镜 / 场次规划（AI 漫剧）

把剧本拆成「场 → 镜」，让每一镜都能独立生图、生视频，又能首尾相接。拆镜没想清楚就先别生成。

## 1. 三种输入模式

| 模式 | 剧本从哪来 | 你做什么 |
|---|---|---|
| A 自写剧本 | 用户给题材 / 设定 | 按短剧结构创作（黄金 3 秒钩子 → 冲突升级 → 反转 → 结尾钩子） |
| B 上传成品 | 用户提供完整剧本 | 只做**拆解 + 提示词生产**，不改动剧情文本 |
| C 小说改剧本 | 用户提供小说 | 提取关键元素 → 转分场剧本（忠实 / 适度 / 创意三档改编） |

模式 B/C 强调「不代笔创作新剧情」；模式 A 允许创作，但仍守下方红线。

## 2. 分镜层级（先选再生成）

- **A 关键分镜**：只定高潮 / 转场等关键镜，其余留给后续。
- **B 场级**：一场一场拆，不定到逐镜。
- **C 逐镜头**：每个镜头单列（默认，漫剧最常用）。
- **D 自定义**：用户指定粒度。

用户没指定层级时先问，不要用关键分镜冒充完整逐镜头。

## 3. 每一镜的字段

```
镜号 shot_index: 3
景别: 中景
角度: 平视
角色: 小林（动作：双手抱头；表情：焦虑）
场景: 办公室，电脑屏幕显示 deadline 倒计时
情绪: 焦虑 / 紧迫
运镜: 缓慢推近（一镜一动词）
时长: 4s
首帧职责: 接上一镜（小林抬头）
尾帧职责: 手机亮起，为下一镜「消息弹出」铺垫
prompt_hint: medium shot, office, young man short black hair glasses holding head, anxious, screen with countdown, slow push-in
```

**运镜 8 术语**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 旋转。一镜只保留一个主运镜（见 `prompt.md` 纪律）。

**景别怎么用**：远景建场与转场；全景交代人物与环境关系；中景是对话主力；近景讲情绪；特写压关键细节（脸 / 手 / 物）。

## 4. 时长与节奏

- 快卡点：2–3s，信息密集、节奏快。
- 沉浸：4–6s，情绪 / 环境铺陈。
- 单集通常 1–3 分钟；按 15–20s 一组闭合生成，每组在台词说完、动作完成或稳定姿态后切分，并写明本组终态与上下游接口。

## 5. 首尾帧衔接（核心）

镜头之间靠首尾帧接，不是硬切：

- 第 N 镜的 `last_frame` == 第 N+1 镜的 `first_frame`（同一张关键帧图）。
- 关键帧图本身用 `references` 垫图保证人物一致，所以衔接既连续又一致。
- 首尾帧职责在分镜阶段就标好（见上字段），生成视频时严格照此取帧。

## 6. 分镜表（确认格式）

```
【漫剧分镜】项目 drama_xxx_20240315 · 共 M 场 / N 镜 · 画幅 9:16

第1镜 | 远景 | 平视 | 场景：城市黄昏天际线 | 无人物 | 情绪：平静 | 运镜：固定 | 5s | 首帧：建场 / 尾帧：切入办公室窗
第2镜 | 中景 | 平视 | 小林坐电脑前皱眉 | 焦虑 | 缓慢推近 | 4s | 首帧：接上镜窗 / 尾帧：屏幕倒计时亮起
第3镜 | 特写 | 俯视 | 手机亮起新消息 | 紧张 | 固定 | 3s | 首帧：接上镜屏 / 尾帧：消息特写
...
```

## 7. 风格跑偏预警

列出 1–3 条本剧最易被拍坏的方式（如：换脸、服装掉色、首尾帧跳变、一镜多运镜），生成时重点盯防。

## 8. 质量准则

- 每镜只有一个主动作、一个主运镜、一个主情绪。
- 相邻镜首尾帧能接上，不凭空换场地 / 换姿态。
- 人物位置 / 朝向跨镜不无理由漂移。
- 台词短、适合口型；每集有明确的开场钩子与结尾钩子。
